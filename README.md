# 捏捏它 / Yellow Plush Playground

一个只有拖拽交互的黄色软胶角色网页。按住角色的脸或身体拖动，局部会被拉伸；松开后弹性回到原位。拖动时角色会从笑脸过渡到咬牙表情。页面没有麦克风、上传、设置、账号、追踪或服务端请求。

## 本地运行

安装 Node.js 后，在项目根目录执行：

```bash
npm run dev
```

打开终端打印的本地地址。也可以将 `dist/` 目录交给任意静态文件服务器托管。

## 项目结构

- `dist/index.html`：单页结构。
- `dist/style.css`：布局与视觉样式。
- `dist/app.js`：WebGL 网格形变、拖拽与回弹；没有第三方运行依赖。
- `dist/assets/smile.png`、`dist/assets/ouch.png`：黄色角色的两张透明 PNG。

形变在浏览器本地完成，不上传指针数据或图片。浏览器不能使用 WebGL 时仍可看静态头像，但无法拖拽形变。

## 素材与许可

角色素材由 LibTV 根据项目作者提供的黄色角色参考生成。仓库只包含本项目生成的角色图片，不包含参考照片、原始三视图或 `rameerez.com` 的图片与代码。本仓库源码及随附的生成素材按 [MIT License](LICENSE) 开源。
